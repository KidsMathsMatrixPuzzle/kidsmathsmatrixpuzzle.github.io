📲 Play Offline — Add to Home Screen

✅ Once added, tap the icon anytime to play — no internet needed!
iPhone / iPad (Safari):
1. Open this game in Safari
2. Tap the Share button (square with arrow ⬆️)
3. Scroll down, tap "Add to Home Screen"
4. Tap "Add" — the game icon appears like an app!
Android (Chrome):
1. Open this game in Chrome
2. Tap the ⋮ menu (top right)
3. Tap "Add to Home Screen" (or "Install App")
4. Tap "Add" — done!
Computer (Chrome / Edge):
1. Open this game in the browser
2. Click the install icon ⊕ at the right of the address bar
3. Click "Install" — it opens in its own window
Mac (Safari) / Firefox (any device):
Bookmark the page, or add it to your Dock/Home Screen from the browser's Share menu — same idea, worded a little differently in each browser.
